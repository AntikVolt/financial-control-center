# Financial Control Center v0.3
Static prototype for cash-flow control.
Includes current cash, 90-day forecast, Green/Yellow/Red warning, Amount Safe to Spend Today, Action Center, recurring events, manual events, CSV import, simple bill-email extraction and local browser storage.
Safe to Spend = max(0, minimum projected balance over 90 days - safety buffer).
GitHub Pages compatible. No backend, authentication, banking connection or automatic email ingestion yet.
